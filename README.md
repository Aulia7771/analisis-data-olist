# Proyek Analisis Data E-Commerce Olist

## Deskripsi

Proyek ini menganalisis hubungan keterlambatan pengiriman,
review pelanggan, dan performa kategori produk
menggunakan dataset publik Olist.

## Setup Environment

```bash
pip install -r requirements.txt
```

## Menjalankan Dashboard

```bash
streamlit run dashboard/dashboard.py
```
